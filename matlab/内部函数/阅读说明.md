# 这里是公式函数，不是独立仿真入口

这些文件需要由教学脚本传入状态、目标和参数。直接点击公式函数的“运行”，
可能提示输入参数不足；这与独立脚本的运行方式不同。

请打开项目根目录的 `start.m`，或对应中文课程文件夹里的 `run_lesson.m`，运行整个文件。
初次运行请使用“运行”（F5），不要只运行中间某一节，因为后面的节依赖前面的初始化。

| 文件 | 归属 |
| --- | --- |
| `adrc_eso_step.m` | LESO的一拍更新 |
| `adrc_leso3_step.m` | 第11讲，二阶对象的三阶LESO一拍更新 |
| `leso_reduced_step.m` | 第20讲，一阶对象的降阶LESO：当前扰动重构与辅助状态更新 |
| `adrc_control.m` | LADRC控制律 |
| `adrc_control2.m` | 第13讲，二阶LADRC控制律 |
| `ltd_step.m` | 线性TD的一拍更新 |
| `td_step.m` | 非线性TD的一拍更新 |
| `td_fhan.m` | 非线性TD内部加速、制动算法 |
| `adrc_fal.m` | 第25讲，静态分段幂函数；不是滤波器或独立ESO |
| `adrc_eso3_step.m` | 第26讲，原三阶非线性ESO导数的欧拉更新 |
| `adrc_eso2_step.m` | 新增一阶对象的非线性ESO，与应用01的C++独立对照 |
| `adrc_nlesf1.m` | 新增单误差非线性反馈，与应用01的C++独立对照 |
| `adrc_sef.m` | 第28讲，原两项fal反馈加显式扰动补偿 |
| `adrc_final_closed.m` | 第28/29讲完整教学对象循环与原模块独立组合 |
| `adrc_final_parameters.m` | 第26～30讲共享教学配置，非机器人默认参数 |
| `adrc_build_final_host.m` | 教学主机构建与CTest，不属于实时控制核心 |
| `adrc_export_figure.m` | 图形导出 |
| `adrc_basic_lesson.m` | 第1~6讲的简明教学实验 |
| `adrc_application_parameters.m` | 四个应用的集中参数，均为仿真假设 |
| `adrc_application_reference.m` | 独立MATLAB对象与控制过程，不读取C++对象作为输入 |
| `adrc_run_application.m` | 运行统一C++例程、核对结果并输出应用图 |
| `adrc_verify_suite.m` | 自动检查课程、核心与应用，不作为个人学习进度 |
| `inspect_adrc1_reference.m` | 参考模型依赖检查 |
| `run_adrc1_reference.m` | 补充原例的实际执行函数 |

本机MATLAB R2025b实测不接受中文`.m`文件名作为直接运行入口，
所以采用中文课程目录和统一的合法文件名 `run_lesson.m`，文件内的标题、提示与图注仍使用中文。
