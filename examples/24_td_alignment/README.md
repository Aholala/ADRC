# 第24讲：非线性TD的C++逐拍核对

`td_runner.cpp` 读取输入信号和实际周期，先记录当前x1/x2与Calc返回的本拍内部加速度，再Update一次，输出下一拍状态。
它不包含控制对象、ESO或限幅策略。

从根目录 `start.m` 选择24运行，MATLAB会自动编译核心、主机测试和本工具。
原库默认参数、原独立模型的零h0覆盖值、两组附加h0比较均在讲义中注明。

可嵌入式核心为 `include/adrc/td2.hpp` 与 `src/td2.cpp`。
CSV读写与命令行解析只属于主机验证，不加入固件控制环。
完整说明见 `docs/24_非线性TD的C++实现.md`。
