# 第18讲：线性TD的最小C++实现与逐拍核对

前置：[第17讲：二阶LADRC的C++组合](17_二阶LADRC的C++组合.md)。

**教学归属：工程实现。** 本讲将第8讲的线性二阶TD整理成独立C++模块，
先核对模块本身，后续再把它与已有C++控制器组合。

## 1. 新模块负责什么

新增 `adrc::LTD2`：

- `include/adrc/adrc.hpp`：初始化、复位、更新与状态读取接口。
- `src/adrc.cpp`：参数检查与两个状态的一拍推进。

| 状态 | 含义 | 若输入为角度 |
| --- | --- | --- |
| x1 | 平滑输出 | rad |
| x2 | 平滑信号的变化率状态 | rad/s |

TD处理的是输入信号，不从测量误差中估计对象扰动。
LESO的z1、z2、z3仍是对象状态与总扰动估计，不能与TD状态混用。

模块无HAL、RTOS、动态内存和系统时钟依赖，也没有电机类型、速度上限或电流限制。
频率参数、初态和实际周期由调用方决定。

## 2. 对照你的原函数

参考：

`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/TD2_L.m:33～35`

```matlab
sys(1) = x(1)+h*x(2);
sys(2) = x(2)+h*(-r^2*(x(1)-u)-2*r*x(2));
```

C++使用相同前向欧拉结构：

```cpp
const float next_x1 = x1_ + dt * x2_;
const float next_x2 = x2_ + dt * (-r_squared_ * (x1_ - input) - damping_ * x2_);
```

Init预先计算 `r_squared=r*r` 和 `damping=2*r`，避免每次重复计算参数。
两个右侧都使用旧状态，确认新值有限后统一保存。

**r是正频率参数，单位1/s，不是变化率上限。** 输入幅值变大，所需变化率峰值也会变化。
主机测试特意检查了变化率峰值可以超过r，避免把原公式误改成限速器。

## 3. 接口怎么用

以下展示调用形式，变量由使用者的工程提供：

```cpp
#include "adrc/adrc.hpp"

adrc::LTD2 td;
bool configured = td.Init(r_td, initial_output, initial_rate);

// 已正确初始化时，每个区间推进一次。
bool updated = td.Update(raw_target_k, dt);
if (updated)
{
    float smooth_next = td.GetOutput();
    float rate_next = td.GetRate();
}
```

Init省略初始状态时，两者均为0；是否适合实际目标接管由调用方决定。
`Reset(output,rate)`只改状态，保留频率参数，不能代替Init。
`GetOutput()`、`GetRate()`只读取，不推进状态。

Update输入为第k拍信号，成功后得到第k+1拍状态。
若与LADRC组合，需要像第14讲一样明确本拍使用哪个TD状态，不重复推进或混淆时间标签。
这一步先不修改控制器，也不把x2加入目标速度前馈。

## 4. 周期与失败保持

固定周期下，当前线性TD的重复离散极点为 `1-r*dt`，理想稳定条件为：

$$
0<r\,dt<2
$$

Update检查该开区间；边界本身不接受。它不是推荐调参范围，也不是任意采样抖动下的稳定保证。
实际每1 ms调用时应传入1 ms，不能仍按原模型的10 ms推进。

以下调用失败并保持原状态，失败Init还保持原参数：

- 未初始化就Update。
- r非正、非有限，或r²、2r无法表示为有效正float增益。
- 初始状态、输入或周期非有限，周期非正或超出当前范围。
- 状态更新产生非有限值。

负的有限输入信号允许使用。实例间状态独立，同一实例由调用方串行访问。
核心不会自动修正周期、清零、钳位变化率或替换为另一种TD。
有限性检查依赖正常浮点语义，不应在开启 `-ffast-math` 后仍假定检查有效。

## 6. MATLAB与原函数怎样核对

教学入口读取原 `MODEL/TD2_L_MODEL.mdl` 的设置：

| 项目 | 原模型值 |
| --- | --- |
| r | 5 |
| h | 0.01秒 |
| 恒值输入 | 10 |
| 正弦输入 | 幅值1、角频率pi/2 rad/s |
| 仿真时长 | 10秒 |

两组均从零状态开始。输入、频率和周期先转为float，以相同数值分别驱动：

1. 真实C++ LTD2。
2. MATLAB `ltd_step.m` 的single运算。
3. 原 `TD2_L.m` 的double更新分支flag=2。

原函数对照也使用相同的已量化输入和参数，不把两份不同输入的差异误算成算法差异。
不执行整个Simulink模型，原函数与模型保持只读。

输出记录每拍Update前后的状态，并检查“下一行before”等于“上一行after”。
最后一行after是额外一步预测，不是最后一行时间标签的当前状态。

## 7. 本次结果与精度含义

恒值和正弦两组各1001拍，更新前后状态与MATLAB single逐拍完全一致。
与原double函数相比，两组各状态最大差值约为：

| 状态 | 最大差值 | 单位 |
| --- | --- | --- |
| x1 | 7.63e-6 | 输入单位 |
| x2 | 1.91e-5 | 输入单位/s |

这是当前参数与构建下的数值差异，不是对任意输入的微分估计误差上限。
单精度常值尾段可以有小幅舍入残差，不能要求x1严格等于输入、x2严格等于0。
本实现保留原公式，没有用额外死区隐藏这些差异。

x2是平滑信号的变化率状态，正弦图中允许出现相位滞后。
恒值输入在起点的跳变没有有限普通导数，因此恒值图不伪造一条全零解析导数。
