# 第26讲：完整三阶非线性ESO与LESO对照

前置：[第25讲：fal](25_fal与非线性ESO入门.md)。本讲归属为**观测器开环教学**，不接控制器或TD。

## 1. 三个状态和原函数

仍用二阶对象 `y_ddot=b0*u+f`。z1估计输出、z2估计变化率、z3估计总扰动。
原 `ADRC1/MyLibrary/ESO2_NL.m` 的flag=1返回连续导数，不是下一拍状态：

$$
e=z_1-y_{meas},\quad
\dot z_1=z_2-\beta_1e
$$
$$
\dot z_2=z_3-\beta_2fal(e,\alpha_1,\delta)+b_0u_{act},\quad
\dot z_3=-\beta_3fal(e,\alpha_2,\delta)
$$

本讲明确选择前向欧拉：`z_next=z+h*dz`，三个右侧均使用同一拍旧状态。
内部公式在 `matlab/内部函数/adrc_eso3_step.m`。
原函数输入顺序是[测量;实际输入]；原 `ESO_2L.m` 则是[实际输入;测量]，脚本分别适配。

## 2. 先匹配局部增益

在abs(e)<delta时，后两条有效系数是beta2*delta^(alpha1-1)、beta3*delta^(alpha2-1)。
以LESO局部目标系数 `[3w,3w²,w³]` 为基准，应设置：

$$
\beta_1=3w,\quad\beta_2=3w^2\delta^{1-\alpha_1},\quad
\beta_3=w^3\delta^{1-\alpha_2}
$$

本讲w=20、alpha1=0.5、alpha2=0.25、delta=0.01，非线性系数约为[60,120,252.982]。
局部误差矩阵为：

$$
A_e=\begin{bmatrix}-\beta_1&1&0\\-\beta_2\delta^{\alpha_1-1}&0&1\\-\beta_3\delta^{\alpha_2-1}&0&0\end{bmatrix}
$$

脚本核对 `max(abs(eig(I+h*A_e)))<1`，当前约0.98。
这只验证当前配置的局部离散极点，不是任意非线性大误差或周期的全局保证。

## 3. 实验条件和来源

优先参考仍是 `D:/ACE/ADRC/ADRC1`，原文件只读。
连续导数逐拍对照原ESO2_NL和ESO_2L；局部匹配、参数及对象是明确新增的教学实验。
原LADRC Demo/tuning.m记录h=0.001、b0=40、wo=40、wc=150；本讲沿用h和b0数值，将局部w设为20，不冒充原完整模型复现。

| 项目 | 设置 |
| --- | --- |
| 对象 | b0=40的二阶积分对象，真值按精确ZOH解析式生成 |
| 实际输入 | 0.5秒变为0.075 A |
| 总扰动 | 1.5秒变为-2 rad/s² |
| 周期/时长 | 0.001秒/6秒 |
| 初态 | 对象为0，观测输出初值0.1，故意产生超过delta的大误差 |
| 测量 | 无噪声、标准差0.001的固定噪声各一组 |

四条轨迹共享同一对象、输入与噪声。初始偏差用于覆盖非线性外侧分支，不能只让它一直在线性区工作后就称为非线性全域验证。
ZOH对象与欧拉观测器的离散方式不同，会有小的确定性暂态和速度估计偏差，沿用第11讲的解释。

## 4. 结果怎样理解

本机R2025b验证共24004次更新，与两个原函数各自推进的轨迹最大差值约1.78e-15。
当前配置下，两者负载后进入2%误差带均约0.373秒，末段扰动估计噪声增量RMS均约0.02325 rad/s²。
零点附近增益匹配、误差又处于内侧时，表现接近是预期结果，不能预设非线性一定更抗噪。
初始大误差阶段的动态仍不同，图中单独展示。

噪声指标是“带噪组减干净组”的末段RMS，不把确定性跟踪偏差混入噪声统计。
