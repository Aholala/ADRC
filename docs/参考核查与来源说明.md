# 参考核查与来源说明

参考仓库只读。以下“代码检查”表示阅读脚本或模型内部结构，不等于已经运行和验证该参考工程。

## ADRC1

保留原课程对TD2_L、TD2_NL/fhan、ADRC_1、ESO2_NL、ESO_2L、NLSEF_2fal和Motion_acc03的来源对应。
既有LESO、TD与ESO3分别保留原状态更新顺序，明确本库b0、单位、离散周期和参数域。
ESO_1rd是空模板，不把它作为降阶观测器的实现来源。RLESO1按一阶对象状态变换推导。
ESO2和NLESF1为本次补充：从一阶扩张模型和单误差Fal反馈构造，接口规则与已有组件一致。

## Adavance_PID

| 文件 | 可以借鉴的内容 | 核查与适配 |
| --- | --- | --- |
| ADRC.m、LADRC.m | 完整TD、ESO、反馈组合，位置与速度两个误差 | 两个观测函数都在z清零后使用z(2)、z(3)，未用上一拍对应状态；不搬入该错误 |
| LADRC.m | 名为TD_Levant的另一种变化率估计实现 | 作为后续对照候选，本次不新增库类 |
| tracer_filter.m | 含测量抖动的TD实验；实际步长与内部时间尺度分开 | 现有TD2已保留dt与h0分离，不重复增加同类组件 |
| TD_controller.m | 用估计变化率参与控制 | 未启用的M=1分支把差分写成两次测量相加，不能作为正确数值求导 |
| PD_Controller_3.m | 根据目标变化速度、加速度提前计算部分作用，即前馈 | 应用对照用于研究目标速度；本轮LADRC2只增加目标速度，不照抄参数 |
| PID_controller.m | 输出受限的基本实验结构 | 负向输出<=-10时被设为+10，符号错误；应用PID独立实现并测试约束 |
| Servo_Joint.slx | 电流响应、机械动态、输出电流/速度限制 | 仅借鉴结构，应用参数显式标为假设，不移植原模型参数当作实车数据 |

参考脚本LADRC的u=u0-z3/b与本库u=(u0-z3)/b使用不同的反馈系数单位。
即使公式可通过换算对应，也不能直接抄kp、kd数值。参考PlantModel还保存上一拍加速度，时序与本库独立对象不同，
不把原图与新图直接比较成算法优劣。

原脚本中的其他独立实验与PMS_Generator电机内部电路模型，不并入当前速度/位置ADRC基础库。
