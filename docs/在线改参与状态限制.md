# 在线改参与状态限制

本文是实际算法库的接口说明。教学材料仍放在matlab/教学，应用模型放在examples和matlab/应用方案，验证放在tests和matlab/验证。

在线改参是运行过程中更换算法系数，同时保留当前动态状态。轨迹限制是约束TD生成的速度和加速度。扰动估计限幅是限制观测器的扰动估计值，它不是电机输出限幅。

## 1. 各组件的对应接口

| 组件 | 保留状态改参 | 手动观测器增益 | 估计扰动上限 | 轨迹速度/加速度上限 |
| --- | --- | --- | --- | --- |
| LTD2 | SetParameters(r) | 不适用 | 不适用 | SetLimits(max_rate,max_acceleration) |
| TD2 | SetParameters(r,h0) | 不适用 | 不适用 | 同上 |
| LESO2 | 带宽或LESO2Config | beta1、beta2 | SetDisturbanceLimit(limit) | 不适用 |
| LESO3 | 带宽或LESO3Config | beta1、beta2、beta3 | 同上 | 不适用 |
| RLESO1 | SetParameters(b0,omega_o,measurement) | 一个观测增益omega_o本来就显式提供 | 同上 | 不适用 |
| ESO2 | SetParameters(ESO2Config) | 原有配置已经显式提供beta | 同上 | 不适用 |
| ESO3 | SetParameters(ESO3Config) | 原有配置已经显式提供beta | 同上 | 不适用 |
| LADRC1 | 带宽或LESO2Config，并提供omega_c | 内部LESO2支持 | 同上，传递给内部LESO2 | 使用外部TD |
| LADRC2 | 带宽或LESO3Config，并提供omega_c | 内部LESO3支持 | 同上，传递给内部LESO3 | 使用外部TD |
| NLESF1 | SetParameters，与Init的参数相同 | 不持有观测器 | 不持有观测器 | 不持有TD |
| NLESF2 | SetParameters，与Init的参数相同 | 不持有观测器 | 不持有观测器 | 不持有TD |

Fal没有配置或动态状态，不需要增加改参接口。RLESO1的模型只有一个辅助状态，不为凑齐接口而增加不存在的多项观测器增益。

## 2. 初始化、改参与失败处理

- Init配置参数并设置初始状态；Reset设置状态；两者保留已经配置的限制。
- SetParameters要求对象已初始化，成功后保留动态状态和限制；无效参数、未初始化或数值无法表示时返回false，整个对象保持原样。
- SetLimits和SetDisturbanceLimit可以在Init前配置。上限允许有限非负值和正无穷，拒绝NaN、负数和负无穷。默认正无穷表示关闭限制，0表示对应上限为零。
- 同一实例由调用方串行访问。多模块组合切换需要调用方统一验证与提交，单个对象成功不表示一组对象都成功。

保留状态不保证控制命令连续。反馈系数或b0改变，即使所有估计状态不动，Calc也可能得到不同输出。需要切换衔接时仍按[库接入说明](库接入与应用说明.md)设置合适初态，或在应用层渐变参数。

RLESO1的扰动估计由q+omega_o*measurement重构。改变omega_o时若只保留q，扰动估计会跳变；因此它的SetParameters需要当前测量，在该测量处保留Calc返回的扰动估计并重算q。浮点相消会产生少量舍入差，不保证逐位相等。

## 3. TD限制的明确顺序

LTD2和TD2采用相同顺序，当前输出与速度分别记为x1、x2，预测区间为dt：

```text
1. 用旧状态计算内部加速度，并限制到 ±max_acceleration。
2. next_x1 = x1 + dt*x2。
3. next_x2 = clamp(x2 + dt*acceleration, ±max_rate)。
4. 所有候选量有效后再提交两个状态。
```

max_rate单位为输入单位/s，max_acceleration为输入单位/s²；角度用rad时分别为rad/s、rad/s²。Calc返回经过加速度限幅的内部命令，速度碰到上限时，实际速度增量可以更小。r是算法尺度参数，不是独立速度上限。

为了同时保留当前速度并遵守加速度上限，SetLimits在新速度上限小于当前速度绝对值时返回false。需要收紧到更低速度时，先由应用减速，或显式Reset到合法初态。Init/Reset同样拒绝超出已配置速度上限的初始速度，不会静默截断它。

默认关闭限制时保持原TD计算。启用限制后的算法多了截断过程，参数和周期是否合适由调用方离线验证；Update不再按理论稳定区间拒绝执行。

## 4. 手动线性观测器增益

观测器增益beta用于按测量误差修正内部估计。LESO2Config包含b0、beta1、beta2；LESO3Config再增加beta3。beta1、beta2、beta3的单位分别为1/s、1/s²、1/s³。库要求所有系数有限、b0非零、beta为正；不在配置接口判断增益是否能使误差收敛。

```cpp
ADRC::LESO2 speed_observer;
ADRC::LESO3 angle_observer;
const ADRC::LESO2Config speed_gains = {2.0f, 3.0f, 2.0f};
const ADRC::LESO3Config angle_gains = {2.0f, 6.0f, 11.0f, 6.0f};
// 示例系数只用于说明接口，不是实机参数。
bool ok = speed_observer.Init(speed_gains);
ok = angle_observer.Init(angle_gains) && ok;
if (ok) {
    ok = speed_observer.SetParameters(speed_gains);
    ok = angle_observer.SetParameters(angle_gains) && ok;
}
```

LADRC1/2提供同样的配置重载，例如Init(angle_gains,omega_c,output,rate,disturbance)和SetParameters(angle_gains,omega_c)，从配置中统一取得b0，不另传一份可能不一致的b0。

当前库不执行运行时稳定性判断。带宽模式和手动模式的Update均只要求dt有限且为正，再在状态提交前检查结果是否有效。参数与周期是否匹配应在MATLAB或使用项目中验证；返回true只代表本次计算成功。

以下理论条件可以用于离线分析，不是库内保护。极点是描述误差随时间放大或衰减的数值，位于单位圆内表示相应固定步长理想误差系统的误差会衰减。令h=dt：

- LESO2令x=h*beta1、y=h²*beta2，要求x>y且4-2x+y>0。
- LESO3再令z=h³*beta3、p=x-y+z，要求0<p<2、8-4x+2y-z>0以及(y-z)*p>z。

这些条件来自对应二次/三次离散误差特征多项式的稳定条件；三阶连续误差系统还应检查beta1*beta2>beta3。它们不保证整个机器人闭环稳定，也不保证任意周期抖动或启用估计限幅后的误差系统稳定。非线性ESO2/3继续保留基本参数有效性检查，不将线性条件套用于它们。

## 5. 扰动估计限幅的生效时刻

对LESO2、LESO3、ESO2、ESO3，SetDisturbanceLimit仅保存上限，不立即改变估计状态。下一次成功Update使用旧状态计算候选值，再截断扰动状态；Init/Reset也截断显式给定的扰动初值。失败的Update不提交任何状态，包括限幅结果。

RLESO1没有独立的扰动状态，其Calc直接限制重构出来的扰动；Update在本次测量处限制候选重构值后换算回q。下一次测量变化可能再次改变未限幅的重构值，所以Calc仍需执行限幅。限制q本身不能正确实现扰动限幅。

LADRC1/2将这个设置传给内部观测器。这里不会限制电机命令，最终输出限制与功率分配继续由调用项目负责。改变上限后估计或输出可能出现过渡，应用应按任务处理。

## 6. 验证入口

tests/runtime_options_test.cpp覆盖全部11个有参数的组件，检查状态保留、失败回滚、手动增益的手算结果、由调用方选择正周期的行为、两类TD的速度/加速度约束、五类独立观测器及LADRC内部观测器的扰动限制。另对非有限输入逐项检查，验证精简后仍不会写入无效状态或覆盖输出。原有测试与MATLAB课程/应用用于检查默认配置的行为是否保留。

## 7. 保护的边界

初始化和改参时检查基本参数域、初值与必要系数是否可表示；运行时检查已初始化、dt为有限正数，以及最终候选结果是否有效。TD在fhan内部保留必要的数值检查，避免无效中间量被符号分支变成一个看似正常的有限输出。

已经验证过配置的ESO/NLESF在内部直接计算Fal，不重复调用公共接口校验同一组alpha、delta。公共Fal仍验证其参数和计算结果。大部分非有限输入会通过公式传播到候选结果，因此在提交结果处统一拒绝，无需逐个入口和中间量重复判断。

理论稳定区间、手动增益的稳定性，以及使用项目的掉线、模式、整车保护策略都不放进每次算法更新。用户显式配置的轨迹和扰动估计限制继续保留，不增加新的默认限幅或自动清零策略。

运行tests/verify_host.ps1和tests/verify_arm.ps1；MATLAB完整检查入口仍是matlab/验证/run_checks.m。上述检查不代表固件链接或实机验证。
