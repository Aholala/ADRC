# 第10讲：一阶对象的二阶LESO——状态含义与采样时序

前置：[第9讲：非线性TD](09_非线性TD.md)。

**教学归属：LESO专题。** 前面第2～4讲已推导过二阶LESO，这一讲把它单独放进MATLAB，
重点观察两个状态和更新时间。本讲不接TD或LADRC控制律，也不扩展新的C++模块。

## 1. 一阶对象，两个估计状态

先用一个已知答案的速度对象：

$$
\dot y=b_0u+f
$$

| 变量 | 含义 | 本例单位 |
| --- | --- | --- |
| `y` | 真实角速度 | rad/s |
| `u` | 实际作用于教学对象的电流 | A |
| `b0` | 已知输入的作用系数 | (rad/s²)/A |
| `f` | 总扰动 | rad/s² |
| `z1` | 对角速度y的估计 | rad/s |
| `z2` | 对总扰动f的估计 | rad/s² |

在这个一阶对象模型中，`z2`估计的是总扰动。完整速度变化率的模型估计为：

$$
\widehat{\dot y}=b_0u+z_2
$$

例如 `b0*u=3`、`f=-2`，对象仍以 `1 rad/s²` 加速。
观测器收敛后应有 `z2=-2`，不是1；加上已知输入贡献后，才得到1。

本例故意省去摩擦和增益误差，因此f直接等于施加的未知项。
实际对象中的总扰动还可以包含内部动态、外部作用和输入增益偏差，不能总把它等同于外部负载。

## 2. 对照你的ADRC_1.m

参考位置：

`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/ADRC_1.m:34～36`

```matlab
e2 = x(3)-u(2);
sys(3) = x(3)+h*(x(4)-B01*e2+u(3));
sys(4) = x(4)+h*(-B02*e2);
```

| 原代码 | 本讲 |
| --- | --- |
| `x(3)`、`x(4)` | 当前估计 `z1`、`z2` |
| `u(2)` | 当前速度测量 |
| `u(3)` | 模型输入作用量，本讲传入 `b0*u` |
| `B01`、`B02` | `beta1`、`beta2` |
| `sys(3)`、`sys(4)` | 下一拍预测 `z1_next`、`z2_next` |

原函数还包含TD状态和控制输出。本讲只对照其 `flag=2` 更新分支中的LESO部分；
原TD的目标和状态保持零，不调用控制输出分支。所传占位参数不是原模型默认参数。
没有运行或修改整个原Simulink模型。

提取公式已在 `matlab/内部函数/adrc_eso_step.m` 中：

```matlab
e = z(1)-measurement;
z_next = [z(1)+h*(z(2)+b0*u-beta1*e);
          z(2)-h*beta2*e];
```

两条右侧使用同一拍旧状态。这个返回值是**下一拍预测**。

## 3. 每一拍怎么安排

本讲沿用原代码的前向欧拉预测式，区间为 `[t[k],t[k+1])`：

1. 获得当前测量 `y_meas[k]`，当前保存的估计是 `z[k]`。
2. 确定这个区间实际作用于对象的 `u[k]`。
3. 按同一时间标签记录 `y[k]、f[k]、z[k]`。
4. 用 `z[k]、y_meas[k]、u[k]` 计算 `z[k+1]`。
5. 对象也推进到下一拍，进入下一个区间。

第4步完成后，结果应与下一拍时间标签对应，不能当作刚获得的当前拍校正值。
若以后改成“预测到当前，再用当前测量修正”的观测器，需要另外设计时序和增益。

嵌入式 `adrc::LESO2::Update()` 也按这一约定工作。
调用前getter读到 `z[k]`，成功调用后读到 `z[k+1]`，每个区间更新一次。
以后接入控制律时，还要明确何时读取状态、计算控制量和限幅，并传入与所建模型对应的实际输入。

注意，`z2+b0*u` 是对象变化率的模型估计；观测器自身的变化率还有纠偏项：

$$
\dot z_1=z_2+b_0u-\beta_1(z_1-y_{meas})
$$

因此 `z2+b0*u` 也不等于含纠偏作用的完整 `dot(z1)`。

## 4. 本讲的教学实验

以下均为教学假设，不是ADRC1完整模型配置或实机默认值：

| 设置 | 数值 |
| --- | --- |
| `b0` | 10 |
| `omega_o` | 20 rad/s |
| `beta1=2*omega_o` | 40 1/s |
| `beta2=omega_o²` | 400 1/s² |
| `h` | 0.001秒 |
| 初始 `y,z1,z2` | 全为0 |
| 已知输入u | 0.5秒时由0变成0.3 A |
| 未知总扰动f | 1.5秒时由0变成-2 rad/s² |
| 仿真时间 | 3秒，无测量噪声 |

先看0.5～1.5秒：`y`持续增加，但 `z2`应保持接近零，因为这段变化已由已知输入解释。
再看1.5秒以后：速度继续增加，`z2`却逐渐变为负数，因为未知项减弱了正向加速。

这里 `omega_o*h=0.02`，满足当前理想误差系统的前向欧拉稳定条件 `0<omega_o*h<2`。
本讲只固定一组带宽和周期，不把稳定边界当作实机推荐调参范围。

## 5. 扰动发生后，为什么不是立刻估出来

以下数值来自本实验，均为当前拍状态：

| 时间/s | 真实y | 真实f | z1 | z2 |
| --- | --- | --- | --- | --- |
| 1.499 | 2.997 | 0 | 2.997 | 0 |
| 1.500 | 3 | -2 | 3 | 0 |
| 1.501 | 3.001 | -2 | 3.003 | 0 |
| 1.502 | 3.002 | -2 | 3.00592 | -0.0008 |

在1.500秒，扰动开始改变后续速度变化率，但速度本身连续，没有突然跳变。
观测器此时看到的输出误差仍为零，所以无法提前知道未知项。

到1.501秒，`e=z1-y=0.002`。用这一拍误差更新：

$$
z_{2,next}=0-0.001\times400\times0.002=-0.0008
$$

这个结果记在1.502秒。它体现了本例的因果关系与所选离散时序，
不是所有ESO都固定“延迟两拍”的通用结论。
