# 第28讲：非线性误差反馈与完整MATLAB闭环

前置：[第27讲](27_非线性ESO的C++实现.md)。教学归属：**NLSEF与闭环组合**。

## 1. 从原两项fal公式开始

原ADRC1/MyLibrary/NLSEF_2fal.m的flag=3输出：

$$u_0=\beta_p fal(e_1,\alpha_p,\Delta)+\beta_d fal(e_2,\alpha_d,\Delta)$$

本讲定义：

$$e_1=v_1-z_1,\quad e_2=v_2-z_2,\quad u_{req}=(u_0-z_3)/b_0$$

v1/v2来自TD当前平滑值和变化率，z1/z2/z3来自ESO当前状态。
v2是可计算的平滑目标变化率，不是对原始阶跃硬求导。
这里新增显式加速度域与b0约定：原NLSEF模块本身不做z3补偿或除b0。
若与原ADRC_2fal的 `k1*fal+k2*fal-z3/b0` 对应，则本讲beta_p=b0*k1、beta_d=b0*k2；不能混用这两套系数。

原ADRC_2fal输出分支有0.75、1.5的指数用法，但其ESO更新仍是线性误差项。
本讲取原独立NLSEF公式，和原TD2_NL、ESO2_NL分别组合，不宣称复现原ADRC_2fal全部配置。

## 2. alpha大于1意味着什么

反馈允许alpha>1。外侧等效增益abs(e)^(alpha-1)会随误差增大而增大，和前面alpha<1的变化方向不同。
本讲alpha_p=0.75、alpha_d=1.5、Delta=0.1，采用第26讲的ESO、非线性TD r=20/h0=0.01。
共享adrc_fal从本讲扩展支持所有有限正指数，仍检查数值溢出；ESO继续限制为0<alpha<=1。

为了匹配线性反馈在小误差区的kp=wc²、kd=2wc，取：

$$\beta_p=w_c^2\Delta^{1-\alpha_p},\quad\beta_d=2w_c\Delta^{1-\alpha_d}$$

wc=8时，系数约为35.99、50.60。匹配只在小误差区成立，大误差动态仍不同。
这些是教学换算值，不是原库NLSEF块的默认参数；wc=8也不同于原完整LADRC示例的150。
原接口用同一Delta数值处理位置与速度误差，保留接口不等于单位可以混用；本教学数值按给定尺度解释，实机必须约定归一化和增益单位，不能直接切换rad/deg。

## 3. 本拍控制顺序

读取本拍TD/ESO状态 → 算两个误差 → 求u0并补偿z3 → 调用方限幅并提交实际输入 → ESO和TD各更新一次。
三个组件可以分别复位和测试，没有额外Manager或隐式状态推进。
目标在0.5秒变为1，3.5秒变为-0.5；2.5秒加入-2扰动；h=0.001，限幅±0.3 A，观察8秒。
这些为教学场景，不是机器人参数；对象仍是b0=40、精确ZOH的二阶积分对象。

## 4. 比较和实际结果

两组反馈都使用同一类非线性TD和ESO；无噪声/有噪声各驱动独立对象，只改变反馈形式。
它是完整闭环比较，不是相同轨迹下的纯滤波器噪声排名。
另外直接调用原三个模块，独立推进自己的状态，验证完整MATLAB组合。

本机32004次主要轨迹更新与原组合最大差值为0。
干净有限幅组，线性/非线性反馈的请求峰值约1.40/4.42 A，累计限幅时间约1.367/1.254秒。
实际输入都受±0.3 A约束；大误差下更大的请求并不增加执行能力。
图中目标下调过程仍有明显超调，非线性组也没有消除它。局部增益匹配不保证有限幅过渡单调，实际应用需要按执行能力验证目标过渡与参数。
末段目标误差很小、维持负载需要0.05 A；带噪末段请求标准差约0.00221 A，两种反馈局部匹配后接近。
因此不预设“非线性一定更快且更抗噪”，也不把当前结果当作任意闭环稳定性证明。
