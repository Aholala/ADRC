# 第23讲：C++降阶一阶LADRC闭环接入

`control_example.cpp` 使用既有 `adrc::RLESO1`，调用方直接计算一阶控制律并执行限幅，不增加公共控制器封装。
编号1～5展示可迁移流程；编号6、CSV和日志只用于主机教学，不加入固件控制环。

运行根目录 `start.m`，选择23。MATLAB会编译降阶核心测试和本例程，再验证三条自主C++闭环。
输入文件只提供目标、外部负载、噪声和区间长度；测量来自C++自己的对象。
负载只作用于对象，不作为额外输入送进观测器。

可嵌入式核心仍只有 `include/adrc/adrc.hpp` 与 `src/adrc.cpp`。
消费工程负责目标、实际测量、时间、输出单位、最终输入处理和失败策略。
完整中文解释见 `docs/23_C++降阶一阶LADRC闭环接入.md`。
