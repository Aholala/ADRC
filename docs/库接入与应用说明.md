# 库接入与应用说明

本页用于选用和接入算法，不代表学习进度。公式教学见[学习路线](学习路线与MATLAB索引.md)。
针对当前ECF27的DJI、DM、VESC及其他驱动，实际反馈、单位和发送路径见[ACE_ECF27电机库接入指南](ACE_ECF27电机库接入指南.md)。

## 1. 两个文件与算法范围

运行库只需main/ALG_ADRC.hpp和main/ALG_ADRC.cpp，使用C++11，命名空间ADRC。
头文件和实现文件各使用一个完整的ADRC命名空间块，组件按功能分区排列。
把main加入搜索路径并编译ALG_ADRC.cpp。原文件已移动，不再引用include/adrc或src。

| 组件 | 含义与已有能力 |
| --- | --- |
| LTD2、TD2 | 平滑输入并估计变化率，分别采用线性和非线性规律 |
| LESO2、LESO3 | 线性观测器，分别估计一阶、二阶对象的状态与总扰动 |
| ESO2、ESO3 | 非线性观测器，首行线性纠偏，后续扰动或变化率行使用Fal |
| RLESO1 | 一阶对象的降阶线性观测器，一个辅助状态结合当前测量重构扰动 |
| LADRC1、LADRC2 | 完整线性控制器，内含对应的LESO；控制计算与状态更新分开 |
| NLESF1、NLESF2 | 一项、两项误差的非线性反馈与显式扰动补偿，无动态状态 |
| Fal | 将误差变换成纠偏量的分段幂函数，无动态状态 |

观测器和TD名称中的数字为内部动态状态数；LADRC的数字为对应对象阶次；NLESF1和NLESF2的数字为误差项数。
NLESF2是原SEF2的新名称，表示包含两项误差的非线性误差状态反馈。
ESO2与NLESF1是本次按一阶模型补充的实现，不声称复制了参考仓库中未实现的模板。

## 2. 选用方式

速度控制是让实际转速跟随目标转速；位置控制是让实际角度或位置跟随目标。
如果输入对应电流/力矩、输出为速度，可从一阶近似和LADRC1开始。
输出为角度时，可研究二阶近似和LADRC2。若输入已是驱动器的目标速度，应重新确定对象关系。
不能按“底盘”“云台”名称直接决定模型阶次。

```cpp
#include "ALG_ADRC.hpp"
ADRC::LADRC1 wheel_speed;
ADRC::LADRC2 gimbal_axis;
ADRC::ESO2 nonlinear_speed_observer;
ADRC::NLESF1 nonlinear_speed_feedback;
```

实例由调用工程持有，跨周期保留。所有参数、方向、时间与最终输出限制均由调用方提供。
不增加电机选型、通信、机器人模式或功率分配默认值，不引入管理层封装。

不同型号不是分别实现算法：同样控制转速的底盘轮和摩擦轮可共用LADRC1，各自持有独立实例和参数。
同样控制角度的舵向与云台可共用LADRC2。任务和输入输出关系决定选型，电机型号决定相应配置与适配。
四个应用入口共用同一个C++仿真例程和MATLAB计算函数；场景分类不是四份生产算法。

## 3. 目标速度接口

目标速度是目标位置每秒变化多少，与电机实测速度不同。
LADRC2保留Calc(target,command)，它与原来的零目标速度控制计算保持一致。
新重载Calc(target,target_rate,command)使用位置误差和目标速度误差：

```text
e_position = target - z1
e_rate     = target_rate - z2
command    = (wc²*e_position + 2*wc*e_rate - z3) / b0
```

z1、z2、z3分别为当前输出、变化率、总扰动估计；wc为配置的控制频率参数，b0为模型输入增益。
target_rate与z2必须使用相同单位。不能把跨圈角度或原始阶跃直接差分当作目标速度。
本轮不增加目标加速度输入。视觉端已有有效目标速度时，可直接使用，不必再由TD重复估计。

## 4. 每次调用顺序

1. 获取本区间开始时的测量与有效目标。
2. 读取当前TD、ESO状态；调用Calc算请求，检查返回值。
3. 应用外部补偿、命令限制和功率分配，提交最终命令。
4. 将与所建模型对应的最终输入及当前测量交给ESO，预测下一次估计。
5. TD若启用，每个区间更新一次，新状态供下一次控制计算使用。

示例中控制量使用A，角度使用rad，速度使用rad/s，时间使用s。
这不是库强制单位：b0、delta、估计状态和所有增益必须与调用工程选定的单位一致。
总扰动的单位是一阶/二阶输出导数单位，不直接等同外部力矩。

最终命令与实际作用量也有差异，例如驱动器存在响应时间。应用模型会明确展示这一差异，
ESO把未显式建模的影响合并估计，不能把仿真可见的真实电流默认当作实车已测得的数据。

## 5. 初始化与切换衔接

切换衔接是让切换后的第一条控制命令与之前的最终命令尽量一致；它不保证之后完全没有过渡。
用当前测量初始化输出、变化率估计，再依据已有命令设置初始扰动估计。

对LADRC1，记当前测量为y、目标为r、已有最终命令为u_hold：

```text
initial_f = wc*(r-y) - b0*u_hold
```

对带目标速度的LADRC2，当前测量变化率为rate、目标速度为r_rate：

```text
initial_f = wc²*(r-y) + 2*wc*(r_rate-rate) - b0*u_hold
```

随后用Init或Reset提交这些初值，检查成功，再调用Calc。当前库的单模块失败不会提交部分状态，
多模块组合流程仍需调用方确定失败策略，不能在失败后继续发送未更新的局部变量。
initial_f此时可能包含两种控制方式之间的差异，之后由观测器调整，不直接当作真实负载测量。
应用03演示2秒从示例PID切到LADRC2，自动检查第一条请求与上次最终命令之差。

## 6. 四套独立应用仿真

打开根目录start.m，将mode设为“应用”，number设为1~4；也可打开各目录run_case.m运行。
这些入口不要求先学完课程。脚本自动构建C++主机例程，不需要MEX。

| 编号 | 观察内容 | 参数和限制 |
| --- | --- | --- |
| 01 单电机转速 | 示例PI、LADRC1、ESO2与NLESF1，负载变化与正反转 | b0=12，wc=12，wo=45，命令±2A |
| 02 舵向角度 | 示例PID、旧零速度基准与新目标速度接口；跨±180°展开 | b0=30，wc=8，wo=30，命令±1.5A |
| 03 视觉云台跟随 | 30Hz目标、40ms延迟、目标速度、重力影响与接管 | 同02；重力影响由ESO整体估计 |
| 04 四轮功率限制 | 示例PI、正确最终输入反馈、错误请求反馈对照 | b0=10，wc=12，wo=40，±3A，教学功率12W |

对象包含两拍命令延迟、一阶电流响应及机械阻力。全部为教学假设，数值来源集中在
matlab/内部函数/adrc_application_parameters.m及C++例程参数函数中；不声称辨识了实车电机。
应用02的连续角度处理属于例程，不内置到通用观测器；实车仍应保留原有舵轮选向与角度处理。
应用03选择由ESO估计重力等总扰动；若实车继续显式重力补偿，必须统一模型和输入定义，不能直接重复叠加。
应用04的12W是演示数值，不是比赛规则，也不替代任何已有功率控制算法。

对比用的PI/PID只是与项目同类结构的示例，参数不是实车原参数。未进行最优调参或实车效果排序。
初次运行记录中，非线性速度方案的请求较小，但目标跟随误差反而更大；不预设非线性更好。

## 7. 结果与验证边界

每套应用输出到build/applications/caseXX：fixture.csv、native.csv、metrics.csv、result.mat/json与中文图。
native.csv由真正的C++核心自主闭环生成。MATLAB独立推进自己的对象与控制状态，不读取C++对象作为输入。
另一层使用同一输入与同一当前状态比较控制和ESO公式，保留单精度幂函数的少量舍入差。

tracking_rms、tail_rms分别为整体与末段误差平方均值的平方根，单位随被控量为rad或rad/s；
请求/最终命令峰值单位A，受限时间单位s；四轮受限时间按每轮平均统计。图中的角度另换为度便于阅读。
这些记录用于评估当前模型、参数和实现，不推广为任意参数稳定性证明。

自动验证入口为matlab/验证/run_checks.m；C++主机检查为tests/verify_host.ps1，ARM对象检查为tests/verify_arm.ps1。
当前覆盖14项主机测试、原课程公式、四套应用；ARM静态库与主机成功仍不代表固件链接或上板通过。

## 8. 在线改参、轨迹限制与观测器配置

SetParameters保留当前动态状态及限制；Init/Reset负责设定初态。两类TD均有速度/加速度限制，五类独立观测器和LADRC1/2均有扰动估计限幅；LESO2/3与LADRC1/2支持手动观测器增益。完整对应表、参数、限制生效时刻及示例见[在线改参与状态限制](在线改参与状态限制.md)。
