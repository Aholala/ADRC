# 第2讲：一阶对象的二阶线性扩张状态观测器（LESO）

> 说明：本节的教学对象、参数和数值与 ADRC1 原例配置分开标注，知识路线继续有效。本讲新增的简明MATLAB入口位于matlab/教学/，可在start.m选择对应编号。讲义含推导和手算，入口参数以脚本和结果记录为准。原例另见[复现记录](00_ADRC1原例与复现基线.md)。

前置：[第 1 步：一阶对象与总扰动](01_一阶对象与总扰动.md)。

本节目标：看懂 ESO 的两个估计状态、误差定义、纠偏方向，并能对应到
参考代码。不在本节实现控制律或选择实机参数。

## 1. 观测器是什么

观测器是一套利用已知输入和测量值，持续估计对象内部量的计算方法。
在电机例子中，输入是电流，测量是转速，希望额外估计的量是影响转速变化的总扰动。
“估计”表示由计算得到的近似值，与传感器直接测到的量不同。
下面先说明本例的信息，再解释为什么把扰动也加入估计。

上一节的对象模型为：

$$
\dot y=b_0u+f
$$

已知输入 `u`，可以测量输出 `y`，但是总扰动 `f` 通常不能直接测到。
直接对有噪声的测量值作差分再减去 `b0*u`，会使求导对噪声非常敏感。
ESO 用模型预测和输出误差纠偏，动态估计对象状态与总扰动。

本节推导先忽略测量噪声。实际接入时使用测量值 `y_meas`，它可能与
真实输出 `y` 有偏差；ESO 的估计同样会受噪声影响。

## 2. “扩张状态”是什么意思

把总扰动也作为一个状态：

```text
真实状态 x1 = y
扩张状态 x2 = f

dx1/dt = x2 + b0*u
dx2/dt = df/dt
```

对象的速度动态仍是一阶。本节采用全阶结构，同时估计对象状态和总扰动，
观测器有两个动态状态，所以称为二阶 ESO。这里的二阶不是把电机速度对象改成二阶。

这不表示不存在一阶 ESO。若直接利用已有的状态测量，可以构造只保存一个
辅助动态状态的降阶 ESO，再结合测量值计算扰动估计。全阶与降阶是不同结构，
不能把本节的两个状态理解成所有 ESO 都必须具备的形式。降阶设计留到后续。

用 `z1`、`z2` 表示对应的估计：

| 估计量 | 希望接近的量 | 本例单位 |
| --- | --- | --- |
| `z1` | 角速度 `y` | rad/s |
| `z2` | 总扰动 `f` | rad/s² |

`z2` 不是完整角加速度的估计。按模型，完整角加速度的估计对应
`z2+b0*u`。也不要把这里的 `z2` 与二阶对象 ESO 中的速度估计混淆。

## 3. 建立最基础的线性 ESO

先按照参考代码的方向定义误差：

$$
e=z_1-y
$$

二阶线性 ESO 写成：

$$
\boxed{\dot z_1=z_2+b_0u-\beta_1e}
$$

$$
\boxed{\dot z_2=-\beta_2e}
$$

其中 `beta1`、`beta2` 是观测器纠偏增益，本节先取正数理解方向。
它们的单位分别为 1/s、1/s²，不是没有单位的任意倍率。

第一条方程分成两部分：

```text
z2+b0*u    根据当前模型和扰动估计，预测速度怎样变化
-beta1*e   根据估计值与测量值的偏差，修正速度估计
```

第二条方程通过不断积累输出误差，调整扰动估计。它省略了未知的 `df/dt`
作为预测输入，并不表示真实扰动必须恒定；变化扰动会形成跟踪误差。

## 4. 为什么误差能帮助估计扰动

若 `z1 > y`，则 `e > 0`：

- `-beta1*e < 0`，直接对速度估计施加向下的修正。
- `-beta2*e < 0`，使扰动估计向下调整，进而影响下一时刻的速度预测。

若 `z1 < y`，两条纠偏项反向作用。

这些是纠偏项的方向，不代表 `z1` 的总变化率必然同向；它还受到 `z2+b0*u`
的影响。也不能凭某一拍误差的符号，就断定真实扰动的符号。

进一步看，定义真实估计误差：

```text
eta1 = z1-y
eta2 = z2-f
```

在无测量噪声、输入与模型一致的情况下，相减可得：

$$
\dot\eta_1=\eta_2-\beta_1\eta_1
$$

$$
\dot\eta_2=-\beta_2\eta_1-\dot f
$$

当 `f` 恒定时，误差系统的特征多项式为 `s²+beta1*s+beta2`。
正的 `beta1`、`beta2` 使该连续线性误差系统稳定，两个估计误差会渐近趋零。
当 `f` 变化或测量含噪声时，需要考虑跟踪能力与噪声之间的取舍。
连续稳定不自动保证某个离散实现和采样周期下也稳定。

## 5. 对照原始 MATLAB 代码

参考文件：
`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/ADRC_1.m`，第 34～36 行。

```matlab
e2=x(3)-u(2);
sys(3)=x(3)+h*(x(4)-B01*e2+u(3));
sys(4)=x(4)+h*(-B02*e2);
```

对应关系：

| 原代码 | 本节符号 | 含义 |
| --- | --- | --- |
| `x(3)` | `z1` | 被控量估计 |
| `x(4)` | `z2` | 总扰动估计 |
| `u(2)` | 测量反馈 | 提供纠偏依据 |
| `e2` | `e=z1-y_meas` | 观测误差，名称中的 2 不是求导 |
| `B01`、`B02` | `beta1`、`beta2` | 两个纠偏增益 |
| `h` | `dt` | 采样周期，单位 s |
| `u(3)` | 模型中的控制作用 | 此处没有显式输入增益系数 |
| `sys(3)`、`sys(4)` | 下一拍 `z1`、`z2` | 离散更新后的估计 |

原代码按单位输入增益或归一化输入约定组织，具体要结合接线判断。
实际以电流为输入时，不能忽略所需的 `b0`。
这个函数中 `x(1)`、`x(2)` 属于 TD，ESO 使用的是 `x(3)`、`x(4)`。

去掉 MATLAB 外壳，保留显式 `b0`，就是：

```text
e = z1-y_meas
z1_next = z1 + dt*(z2+b0*u-beta1*e)
z2_next = z2 + dt*(-beta2*e)
```

两个新状态都由同一拍旧状态计算，最后再一起保存。
输入 `u` 应与这段预测区间对应；具体离散时序将在仿真与实现阶段说明。

## 6. 手算一次更新

以下是假设的教学参数，不是实际机构默认参数：

```text
y_meas = 1.0 rad/s
z1 = 0.8 rad/s
z2 = 0 rad/s²
b0 = 10 (rad/s²)/A
u = 0.5 A
beta1 = 20 1/s
beta2 = 100 1/s²
dt = 0.001 s
```

由此：

```text
e = 0.8-1.0 = -0.2 rad/s
dz1/dt = 0 + 10*0.5 - 20*(-0.2) = 9 rad/s²
dz2/dt = -100*(-0.2) = 20 rad/s³

z1_next = 0.8 + 0.001*9 = 0.809 rad/s
z2_next = 0 + 0.001*20 = 0.020 rad/s²
```

速度估计偏低，因此产生向上的纠偏，扰动估计也向上调整。
一拍算完并不代表已经准确估计总扰动，估计过程需要随时间继续运行。
ESO 接收输入和测量反馈，输出估计量；这一阶段尚未产生控制命令。

## 7. 自查题与下一步

保持上述其他条件，将 `z1` 改成 `1.2 rad/s`：

1. `e` 是正还是负？
2. `z2` 的更新方向是增大还是减小？

随后在已知真实扰动的仿真对象上检查估计效果。
