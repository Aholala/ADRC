仍以 `D:/ACE/ADRC/ADRC1` 的 `MyLibrary/ADRC_1.m` 为全阶更新与反馈结构的参考。
降阶结构沿用第20讲推导，原 `ESO_1rd.m` 空模板没有提供这一实现。

## 1. 先认清这一讲控制什么

对象是速度的一阶模型：

$$
\dot y=b_0u+f
$$

y为角速度，r为目标角速度，u为实际模型输入，f为角加速度单位的总扰动。
这不是第19讲的二阶角度对象，不使用那个二阶LADRC控制律。

全阶一阶LADRC使用输出估计z1、扰动估计z2：

$$
u_{req}=\frac{\omega_c(r-z_1)-z_2}{b_0}
$$

降阶形式直接使用测量y_meas，以及本拍重构的扰动估计：

$$
\hat f=q+\omega_o y_{meas},\qquad
\boxed{u_{req}=\frac{\omega_c(r-y_{meas})-\hat f}{b_0}}
$$

其中ωc控制目标反馈的强弱，ωo控制观测动态，两者职责不同。
MATLAB复用已有的 `adrc_control` 公式，传入 `[measurement;f_hat]`；
这两个值是本次控制计算的反馈量，不是两个独立积分的降阶观测器状态。

| 量 | 从哪里来 | 用在哪里 |
| --- | --- | --- |
| r | 调用方目标 | 控制律 |
| y_meas | 当前传感器测量，本例为真值加噪声 | 降阶输出重构与速度反馈 |
| q | 跨周期保存的唯一降阶动态状态 | 重构hat_f并预测下一拍q |
| hat_f | q+ωo*y_meas | 扰动补偿 |
| u_req | 控制律计算 | 交给调用方输出处理 |
| u_act | 最终限幅后的实际模型输入 | 对象与观测器同时使用 |
| f真值 | 仿真对象的负载设置 | 只驱动对象与核对结果，不送给控制器 |

## 2. 一拍的正确顺序

在k拍开始时，已经保存q[k]，现在获得y_meas[k]：

1. 用q[k]和当前测量重构hat_f[k]。
2. 计算当前控制请求u_req[k]。
3. 调用方完成限幅，提交本区间的u_act[k]。
4. 用同一区间的u_act[k]推进q[k+1]。
5. 下一拍收到新测量后，再重构新的扰动估计。

```matlab
% 当前q和measurement已经可用。
f_hat = q + omega_o*measurement;
requested = adrc_control(target,[measurement;f_hat],b0,omega_c);
applied = max(-input_limit,min(input_limit,requested));

% 此处将applied提交给对象；再用最终实际输入推进观测器。
[q_next,current_f_hat] = leso_reduced_step(q,applied,measurement,b0,omega_o,dt);
% current_f_hat仍属于本拍；保存q_next，在下一周期使用。
```

`leso_reduced_step` 的第二个输出是当前重构值，重复计算它不会推进额外状态。
不要为了取得f_hat，先用假定输入0调用一次更新，再在控制计算后更新一次；每个采样区间只推进一次。
这里展示的是成功路径，实际库实现仍需检查参数与更新返回状态。

hat_f[k]只依赖已有q和当前测量，不依赖尚未决定的u[k]。
因此这里没有要求解“控制量依赖自己”的代数方程。
仿真对象没有输入到当前输出的代数直通，提交的输入影响后续采样。

全阶比较组仍采用已学顺序：先用当前z算控制，再用当前测量和实际输入预测下一拍z。
两种结构的当前测量使用方式不同，不能用“两个状态名字相同”来替代时序分析。

## 3. 为什么这样能跟踪目标

在无噪声、输入增益匹配、没有限幅的理想条件下，代入对象得到：

$$
\dot y=\omega_c(r-y)+(f-\hat f)
$$

如果扰动估计准确，速度动态近似为：

$$
\dot y=\omega_c(r-y)
$$

目标固定时，速度偏差按一阶动态衰减。第20讲给出扰动估计误差也按其观测动态衰减。
在本讲前向欧拉、常值区间输入下，令e_y=y-r，e_f=hat_f-f，固定r、f时：

$$
\begin{bmatrix}e_y[k+1]\\e_f[k+1]\end{bmatrix}
=\begin{bmatrix}1-h\omega_c&-h\\0&1-h\omega_o\end{bmatrix}
\begin{bmatrix}e_y[k]\\e_f[k]\end{bmatrix}
$$

理想离散误差极点分别为1-h*ωc、1-h*ωo。
本讲ωc=8、ωo=20、h=0.001，对应0.992和0.98。
这是给定理想模型下的说明，不是对噪声、时延或任意饱和闭环的稳定性承诺。

若发生限幅，实际对象变成：

$$
\dot y=\omega_c(r-y)+(f-\hat f)+b_0(u_{act}-u_{req})
$$

观测器用实际输入，可以避免把已知的限幅差额误认为未知扰动；
但它无法凭空增加执行能力，目标过渡仍会受限。
若最后需要维持的输入本身超出限幅范围，也不能期待稳态零误差。

## 4. 这次MATLAB比较哪些工况

| 教学项目 | 设置与来源 |
| --- | --- |
| 对象与观测器 | 沿用第20讲：b0=10、ωo=20、h=0.001 |
| 控制带宽 | ωc=8，沿用已有一阶LADRC教学设置 |
| 初态 | 速度3 rad/s、目标3 rad/s、初始扰动估计0 |
| 目标变化 | 0.5秒升为4 rad/s，2.5秒降为2 rad/s |
| 未知负载 | 1.5秒从0变为-2 rad/s² |
| 工况一 | 无噪声、无限幅 |
| 工况二 | 无噪声、外部±0.3 A限幅 |
| 工况三 | 测量噪声标准差0.001 rad/s、同样±0.3 A限幅 |
| 时长 | 5秒，末段统计4.5～5秒 |

以上是教学配置，不是原完整模型参数或机器人默认值。原参考文件只读。
三种工况各有全阶和降阶两条独立闭环，总计六条。
两者各自驱动自己的对象，所以真实轨迹与测量会不同；带噪组共用的是同一份噪声序列。
它比较整体闭环行为；要隔离观测器的纯噪声特性，仍看第20讲固定同轨迹实验。

干净组初始化为q=-20*3=-60，全阶z=[3;0]，首拍控制均为0。
带噪组按各自第一次测量对齐内部初态；当前测量的速度反馈仍会产生相应请求，不能保证首拍请求恰好为0。
如果真实初始负载未知，初始扰动估计也未必正确，不能直接照搬本例零负载接管假设。

## 5. 看图时重点解释三件事

第一张图看干净有限幅组的实际速度；第二张图看降阶控制器的请求和实际输入。
目标下调时请求峰值绝对值约1.4 A，实际输入仍被限制在0.3 A以内。
两者差额没有作为真实输入施加给对象，观测器也只接收实际输入。

第三张图看负载发生后的估计。当前无噪声降阶估计在负载作用于下一次测量后，
先变为-0.04，再变为-0.0792 rad/s²，和第20讲的独立递推一致。
干净组中的已知限幅输入不会额外污染扰动估计；这依赖于匹配的b0、对象假设和实际输入反馈。

第四张图看末段控制请求的噪声波动。
把降阶控制公式展开：

$$
u_{req}=\frac{\omega_c r-q-(\omega_c+\omega_o)y_{meas}}{b_0}
$$

固定q与目标时，当前测量噪声对请求存在直接通道。
全阶比较组先按当前观测状态算控制，当前新测量通过之后的观测更新影响后续请求；
这并不表示全阶控制器不受噪声影响。
本讲的控制请求波动包含整个闭环作用，不能全部归因为单独的观测器滤波性能。

## 6. 与原代码怎样核对，结果保存在哪里

入口逐拍核对 `ADRC_1.m` 的两处：

- flag=3：原反馈输出除以显式b0，与两种结构实际采用的反馈量核对。
- flag=2：全阶比较组z1/z2与原第3、4状态核对；原TD状态保持0，不接目标处理。

降阶结构另核对包含噪声差的独立递推；干净组核对扰动阶跃解析解；
无限幅干净组再用独立的[y;hat_f]离散矩阵推进完整闭环，不读取主循环的q或测量结果。
另外检查限幅确实发生、实际输入一致、状态标签、有限数值与干净末段平衡。
最后一行保存的下一拍预测不算成额外采样区间，限幅时间只累计实际模拟的5000个区间。

输出位于 `build/lesson21/`：

- 六个按工况与结构命名的CSV：当前真值、测量、反馈、估计、请求、实际输入和内部状态。
- `closed_loop_metrics.csv`：输入峰值、限幅时间、负载段峰值误差与末段指标。
- `load_step_timing.csv`：干净有限幅降阶组在负载前后几拍的量，供手算。
- `reduced_ladrc_result.mat`：变量result，含中文教学归属、参数、六组数据与核对残差。
- `reduced_ladrc_comparison.fig/.png/.svg`：中文教学图。

负载段峰值误差按1.5～2.5秒统计，包含该段开始时尚存的目标过渡误差；不是严格隔离的负载响应实验。
末段请求标准差也只是本次闭环记录的波动指标。
无噪声稳态所需输入为-(-2)/10=0.2 A，小于0.3 A限幅，具备本例所需的维持能力。
