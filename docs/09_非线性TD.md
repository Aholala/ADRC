## 1. 从你给的原代码开始

参考文件：

`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/TD2_NL.m`

第33～35行：

```matlab
function sys = mdlUpdates(x,u,r,h,h0)
sys(1) = x(1) + h*x(2);
sys(2) = x(2) + h*fhan(x(1)-u,x(2),r,h0);
```

为了与电机控制输入区分，下面把这里的输入 `u` 记作 `v`：

$$
x_{1,k+1}=x_{1,k}+h x_{2,k}
$$

$$
x_{2,k+1}=x_{2,k}+h f_h,\qquad
f_h=\operatorname{fhan}(x_{1,k}-v_k,x_{2,k},r,h_0)
$$

- `x1`：平滑后的目标值。
- `x2`：平滑目标的变化率状态。
- `fh`：决定这个变化率怎样变化。

两条右侧都用旧状态，不能先更新 `x1` 再把新值代入第二条。
这两行与线性TD的结构相同，改变的是第二行计算变化率变化的规律。

## 2. 为什么还没到目标，就要开始减速

假设输入是角度，目标为1，当前 `x1=0.95`、`x2=2`。
虽然角度还差0.05，但正以每秒2个角度单位向前变化，继续加速就可能冲过目标。
因此，`fhan` 必须同时看偏差 `x1-v` 和当前变化率 `x2`。

使用本讲基准 `r=20, h=0.01, h0=0.01`，原函数给出：

```text
fh       = -20
下一拍x1 = 0.95 + 0.01*2     = 0.97
下一拍x2 = 2    + 0.01*(-20) = 1.8
```

下一拍仍在接近目标，但变化率已经减小。这就是提前制动。
这里的“加速、制动”描述TD内部信号的运动，不代表电机已经产生对应动作。

## 3. 三个参数要分开理解

设输入单位为 `U`：

| 参数 | 在本实现中的作用 | 单位 |
| --- | --- | --- |
| `h` | 每次状态更新对应的实际时间步长 | 秒 |
| `h0` | `fhan` 内部的预测与切换尺度 | 秒 |
| `r` | `fh` 的幅值上限 | U/秒² |

原公式保证：

$$
|f_h|\le r,\qquad |x_{2,k+1}-x_{2,k}|\le hr
$$

**这里的 `r` 不是 `x2` 的幅值上限。** `x2` 可以持续累积。
它也与第8讲线性TD中单位为每秒的频率参数 `r` 含义不同，不能直接复用调参值。

输入为角度时，`x2` 是角速度，`fh` 是角加速度；
输入为速度时，`x2` 是加速度，`fh` 则是加速度的变化率。

`h0` 可以与 `h` 相等，也可以在合理范围内取不同值。
改变 `h0` 不会改变真实调用周期，不能用它代替 `h`。
本节对比固定 `h=0.01`，只改变 `h0`；尚未推导任意步长与参数组合的稳定范围。

## 4. 再读fhan里面的变量

原文件第41行的函数写成 `fhan(x1,x2,r,h)`。
**这个局部形参 `h` 接收的是外层的 `h0`**；局部 `x1` 接收的是外层偏差 `x1-v`。
教学文件改用 `error, rate, r, h0` 命名，逐式保留原算法：

```matlab
d  = r*h0;
d0 = h0*d;
y  = error + h0*rate;
a0 = sqrt(d^2 + 8*r*abs(y));

if abs(y) > d0
    a = rate + (a0-d)*sign(y)/2;
else
    a = rate + y/h0;
end

if abs(a) > d
    fh = -r*sign(a);
else
    fh = -r*a/d;
end
```

先按用途读，不急着背公式：

| 中间量 | 如何理解 |
| --- | --- |
| `y=error+h0*rate` | 按当前变化率向前看一段时间得到的偏差量 |
| `d=r*h0` | 变化率尺度，单位U/秒 |
| `d0=r*h0²` | 偏差尺度，单位U |
| `a0`、`a` | 用于判断调节方向和强度的中间量，单位U/秒 |
| `fh` | 最终给出的变化率变化量，单位U/秒² |

变量名 `a` 不表示它就是物理加速度。
最后一个分支可以看成：先根据 `a` 决定方向，再把 `fh` 限制在 `[-r,r]` 内；
在小范围内使用连续比例修正，避免始终只在两个端点之间切换。
前一分支中的平方根表达式用于结合偏差和当前变化率决定加速或制动；其推导留到后续。

## 5. h0为什么会影响接近目标时的表现

当两个条件同时成立：

$$
|y|\le d_0,\qquad |a|\le d
$$

原分支可化为：

$$
a=x_2+\frac{e+h_0x_2}{h_0}=\frac{e}{h_0}+2x_2
$$

$$
f_h=-\frac{e}{h_0^2}-\frac{2x_2}{h_0},\qquad e=x_1-v
$$

这与第8讲的线性形式相似，局部等效频率为 `1/h0`。
所以本例中较大的 `h0` 会让接近目标时的修正更缓，正弦跟踪滞后也更明显。
这一结论有上述分支条件，不能用局部公式替代完整非线性算法。
