# 第6讲：一阶LADRC的输出限幅与LESO输入反馈

> 说明：本节的教学对象、参数和数值与 ADRC1 原例配置分开标注，知识路线继续有效。旧实验入口已停用，后续统一用 MATLAB；当前进度见 [第 7 步](07_初始化与无扰接管.md)，原例另见 [复现记录](00_ADRC1原例与复现基线.md)。

前置：[第 5 步：一阶 LADRC 闭环](05_一阶LADRC闭环.md)。

本节目标：区分控制器请求、执行器实际输入和 ESO 的模型输入，理解限幅
为什么会影响扰动估计。沿用已有核心与接口，仅增加测试、仿真实验和说明。

## 1. 控制器请求不一定能被执行

上一节计算的控制量是：

$$
u_{\mathrm{req}}=\frac{\omega_c(r-z_1)-z_2}{b_0}
$$

如果执行器只能在上下限之间工作，实际输入为：

$$
u_{\mathrm{act}}=\operatorname{sat}_{u_{\min}}^{u_{\max}}(u_{\mathrm{req}})
$$

教学例子：请求 0.8 A，但上限为 0.2 A，电机实际只得到 0.2 A。
原控制公式并不会自动知道下游执行器改变了它的请求。

本节的限幅属于仿真执行器，算法核心不添加机器人电流上限、模式或保护策略。

## 2. ESO 应该使用哪个输入

对象实际上满足：

$$
\dot y=b_0u_{\mathrm{act}}+f
$$

因此，ESO 的已知模型输入也应对应 `u_act`。
正确时序仍然是：

```text
Calc(target,requested)                         // z[k] -> 控制请求
applied = 调用方执行器处理(requested)          // 区间 k 的实际模型输入
UpdateObserver(applied,measurement_k,dt)       // z[k] -> z[k+1]
```

限幅后值只在执行器能充分跟随它、且单位和时序一致的模型前提下，才代表
实际作用量。存在电流内环动态、延迟或其他输出处理时，需要进一步核对。
若后面还有功率限制等处理，仅把前一级限幅值送回并不一定足够。

## 3. 错把请求值送回，会估计到什么

若 ESO 使用 `u_req`，把真实对象改写为：

$$
\dot y=b_0u_{\mathrm{req}}
       +\underbrace{\left[f+b_0(u_{\mathrm{act}}-u_{\mathrm{req}})\right]}_{f_{\mathrm{req}}}
$$

此时，观测器除了物理总扰动，还会吸收已知的限幅差额。
它相对于所收到的错误模型输入估计的是 `f_req`，不能把这个估计直接解释为原模型中的 `f`。

例如，无负载 `f=0`，`b0=10`，请求 0.8 A、实际 0.2 A：

```text
f_req = 0 + 10*(0.2-0.8) = -6 rad/s²
```

观测器看到的输出变化比所期待的小，于是将这部分差额吸收为负扰动。
控制律再减去负的扰动估计，就可能进一步增加请求；执行器仍然无法执行，
内部量可能持续积累，退出饱和后出现明显超调或恢复缓慢。

这解释了为什么仅限制最终电流、却不让 ESO 知道，不一定足够。
反馈限幅后的输入可保持模型输入一致，也是常见的观测器抗饱和处理方式；
它不是对任意延迟、执行器动态和参数都成立的稳定性保证。

## 4. 两个实验，分别看什么

两条闭环使用相同核心和相同限幅：

- `applied`：对象和 ESO 都接收限幅后的实际输入。
- `requested`：对象接收实际输入，ESO 故意接收未执行的请求值，作为反例。

统一教学设置：`b0=10`、`omega_c=8`、`omega_o=40`、`dt=1 ms`，电流限幅为 ±0.2 A。
无测量噪声、无输出变化率限制、无执行器延迟。

### 实验一：可以达到的目标，瞬态发生饱和

对象：`dy/dt=10*u_act`，真实总扰动为零。
0.2 s 将目标改为 1 rad/s，2 s 改为 0.25 rad/s，总时长 4 s。

瞬态时电流不足以按原先设计的速度跟踪，但经过足够时间可以到达目标。
看第一次目标降低前的速度峰值：

| ESO 输入 | 速度峰值，目标为 1 rad/s |
| --- | --- |
| 实际输入 | 约 0.999997 rad/s |
| 原始请求 | 约 1.44733 rad/s |

整个实验的最大 `|z2-f|` 分别约为 0.0000154 和 20.49 rad/s²。
这些是当前数值例子的结果，不是所有对象的误差上限。

### 实验二：目标超过稳态能力，再降低目标

对象变为：

$$
\dot y=-y+10u_{\mathrm{act}}
$$

实际正向最大输入是 0.2 A。稳态时：

$$
0=-y+10\times0.2\quad\Longrightarrow\quad y_{\max}=2\ \mathrm{rad/s}
$$

因此，0.2 s 给出 3 rad/s 的目标时，这个例子无法在稳态达到它。
即使 ESO 输入完全正确，也不能改变这个物理约束。
3 s 将目标降为 0.5 rad/s，继续运行到 8 s，观察恢复过程。

这一次实验中：

| ESO 输入 | 全程最大请求电流 | 降低目标后的恢复时间 |
| --- | --- | --- |
| 实际输入 | 2.4 A | 约 0.692 s |
| 原始请求 | 约 65.27 A | 约 4.030 s |

恢复定义：进入目标 ±0.02 rad/s，并在剩余仿真时间内保持。
这是有限仿真窗口的判据；请求电流可以很大，但实际电流始终被限制在 ±0.2 A。

物理总扰动在这个实验中是 `f=-y`，两条闭环的真实输出不同，真实 `f` 也各自不同。
画误差时必须用各自的 `f`，不能把两条曲线都减去同一个假定扰动。
