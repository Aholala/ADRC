# 完整C++接入示例

先看 `control_example.cpp` 循环中的编号1～6：

1. 获得当前输出测量。
2. 读取当前TD平滑值。
3. 调用LADRC的Calc计算请求。
4. 调用方完成输出限制并提交最终输出。
5. 用适用于模型的实际输入更新LESO。
6. TD推进一次，新值供下一拍使用。

CSV读写、命令行参数和编号7的对象模型属于主机验证，不需要加入STM32工程。
本例的v2只记录，未加入目标速度前馈；限幅同样不在库核心内。

在MATLAB中运行 `D:/ACE/Infantry_dev/ADRC/start.m`，选择第19讲，
会自动编译三个核心的主机测试与本例，运行两组闭环并输出中文图形。
需要g++，编译器探测方式沿用前几讲。

消费工程只需编译以下核心源文件并配置include头文件路径：

- `src/adrc.cpp`

完整说明在 `docs/19_完整C++接入示例.md`。本例通过主机验证，尚未固件链接或上板验证。
