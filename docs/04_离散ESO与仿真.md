## 1. 从参考代码提取核心

`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/ADRC_1.m`
第 34～36 行提供了前向欧拉 ESO 的参考更新结构。
保留它的误差方向，显式补上输入增益，并用 `z1`、`z2` 命名观测器状态：

```cpp
const float error = z1 - measurement;
const float next_z1 = z1 + dt * (z2 + b0 * input - beta1 * error);
const float next_z2 = z2 - dt * beta2 * error;
```

`beta1=2*omega_o`、`beta2=omega_o²`，都由调用方提供的 `omega_o` 计算。
两个新状态始终使用同一拍旧状态，最后一起写回。

实现位于：

- `main/ALG_ADRC.hpp`：`ADRC::LESO2` 接口。
- `main/ALG_ADRC.cpp`：前向欧拉计算与数值参数检查。

`2` 指观测器的两个动态状态，对象仍按一阶建模。
该实现无 HAL、RTOS、动态内存或系统时钟依赖，不指定任何机器人参数。

## 2. 把时间标签对齐

这一版是预测式实现，时刻 `t[k]` 保存的是 `z[k]`：

1. 得到当前测量 `y_meas[k]`。
2. 给定下一采样区间 `[t[k],t[k+1])` 内的模型输入 `u[k]`。
3. 使用 `z[k]`、`y_meas[k]`、`u[k]` 运行一次 `Update()`。
4. 得到 `z[k+1]`，对应下一拍的状态预测。

输入应是与所建模型对应的实际作用量或适用近似下的指令量，单位与 `b0`
一致。若存在功率限制等输出处理，模型输入必须对应处理后作用于对象的量。

本方法不是“用上一拍输入预测到当前拍，再用当前测量立即修正”的当前
观测器，二者的计算时序和增益设计不能直接混用。
后续若改成当前观测器，需要单独推导和验证。

仿真 CSV 在每次更新前记录 `y[k]`、`f[k]`、`z[k]`，按同一时刻比较；
随后对象与观测器分别推进到下一拍。未知扰动刚发生跳变时，估计不可能
在尚未看到输出变化之前就知道跳变值。

## 3. 最小接口

```cpp
#include "ALG_ADRC.hpp"

ADRC::LESO2 observer;

// 所有参数由使用者给定；下面是接口调用形式，不是实机参数配置。
bool configured = observer.Init(b0, omega_o, initial_output, initial_disturbance);

// 在已正确初始化的前提下，从 k 拍预测到 k+1 拍。
bool updated = observer.Update(input_k, measured_output_k, dt);
if (updated)
{
    float predicted_output_next = observer.GetOutput();
    float predicted_disturbance_next = observer.GetDisturbance();
    // 使用者按对应时间标签读取和使用结果。
}
```

`Init()` 成功会设置参数和初始状态，`Reset(output,disturbance)` 只重设状态。
初值由使用者决定，调用方保证同一个实例串行更新、每区间推进一次。

未初始化、非有限参数、零输入增益、非正带宽、无法表示的增益、无效周期或状态运算溢出时返回 `false`，保留原配置或状态。
当前库不再按 `omega_o*dt` 的理论稳定区间阻止更新，周期与参数是否匹配由调用方离线验证。
允许负的 `b0`。不自动替换周期，不限制状态幅值；异常时业务如何处理由调用方决定。
这些检查依赖 IEEE 浮点语义，不应以 `-ffast-math` 编译后仍假设检查有效。
有效范围内仍可能存在浮点精度损失，单位尺度与采样抖动需在消费工程核对。

嵌入式工程添加 `main/ALG_ADRC.cpp`，并把 `main/` 加入头文件搜索路径即可。

## 4. 仿真对象和三种情况

仿真对象为：

$$
\dot y=-ay+bu+d
$$

相对于 ESO 的 `b0`，真实总扰动为：

$$
\boxed{f=-ay+d+(b-b_0)u}
$$

对象用 double 精度解析 ZOH 公式更新，输入和外部作用在每个区间内保持不变。
ESO 则运行实际 `float` C++ 核心。此前的绘图程序不另写一份 ESO 代替被测实现。

所有示例使用 `b0=10`、`dt=1 ms`，比较 `omega_o=10、20、40 rad/s`。
输入在 1.5 s 从 0.5 改为 0.2，外部作用 `d` 在 0.5 s 从 0 改为 -3，
在 2.5 s 改为 +1。数值均为教学假设。

| 场景 | 实际对象 | 要观察什么 |
| --- | --- | --- |
| `load_steps` | `a=0`、`b=b0=10` | `z2` 对外部作用变化的估计 |
| `model_error` | `a=0.6`、`b=8`、`b0=10` | `z2` 跟踪合并后的总扰动，而非仅 `d` |
| `measurement_noise` | 匹配对象，测量叠加 ±0.03 rad/s 采样噪声 | 估计速度与噪声敏感性的取舍 |

同一场景的三个观测器读取相同的输入和测量，包括相同的噪声序列。
随机种子固定，但 C++ 标准库之间不保证生成的浮点分布序列逐位相同。

这一次运行中，匹配无噪声对象在 `omega_o=20` 时，3～4 s 区间的扰动估计
RMS 误差约为 `0.000302 rad/s²`。

扰动跟踪误差。需要区分这种变化扰动误差、离散近似误差和测量噪声。
