# 第8讲：线性二阶跟踪微分器（TD）——平滑目标与变化率

前置：[第7讲：一阶LADRC与二阶LESO的初始化与接管](07_初始化与无扰接管.md)。

**教学归属：TD目标信号处理。** 本讲独立观察 TD，不连接 LESO 或 LADRC 闭环。
LESO 和 LADRC 已在前几讲入门，后续仍有专门的扩展专题，见 [学习路线](学习路线与MATLAB索引.md)。

## 1. 输入与两个状态

输入记为 `v`，TD 保存：

| 状态 | 含义 | 输入为角度时的单位 |
| --- | --- | --- |
| `x1` | 平滑后的输入 | 角度单位 |
| `x2` | 平滑信号的一阶变化率 | 角度单位/秒 |

输入为速度时，`x1` 是平滑速度，`x2` 是对应加速度。
这里的 `x2` 不承担总扰动估计的职责；前几讲一阶对象的 LESO 中，`z2` 才对应总扰动估计。
TD 的二阶表示两个动态状态，不要求后面的 LADRC 必须控制二阶对象。

## 2. 直接看你给的原代码

优先参考：

`D:/ACE/ADRC/ADRC1/贺庆毕业论文ADRC全集包仅用于内部共享不要外传/MyLibrary/TD2_L.m`。

第33～35行：

```matlab
function sys = mdlUpdates(x,u,r,h)
sys(1) = x(1) + h*x(2);
sys(2) = x(2) + h*(-r^2*(x(1)-u)-2*r*x(2));
```

在这个文件中，`u` 是 TD 输入信号，不是电机电流。
`r` 是线性 TD 的频率参数，不是前几讲表示目标值的数学符号 `r`。
读取不同文件时，先看该符号属于哪个模块。

其连续模型为：

$$
\dot x_1=x_2
$$

$$
\dot x_2=-r^2(x_1-v)-2rx_2
$$

`-r²(x1-v)` 根据跟踪偏差推动信号接近输入，`-2r*x2` 提供阻尼。
这是阻尼比为1的线性二阶系统。
`r` 在这里不是变化率上限或加速度上限；非线性 `fhan` 中同名参数的定义将在下一讲单独说明。

## 3. 为什么这两行要一起看

第一行根据旧变化率更新平滑值，第二行根据旧偏差和旧变化率计算下一拍变化率。
`sys` 是下一拍，`x` 是当前拍。两条右侧均使用旧状态，不能先修改某个状态后再混入另一条右侧。

只要 `h` 是采样周期，原更新就是前向欧拉离散形式。
对应离散极点为 `1-r*h`，固定周期下理想稳定条件为 `0<r*h<2`。
这不是推荐调参范围，逼近边界时波形和离散近似仍可能很差。

## 6. 这张图怎样读

第一行是恒值输入，从零状态开始：

- 左图：输入直接为10，`x1` 逐渐跟上。
- 右图：`x2` 先增大、随后回到零，表示过渡结束后平滑值不再变化。
- `r` 较大时本例过渡更快，所需变化率峰值也较高。

第二行是正弦输入：

- 左图：`x1` 相对输入有幅值变化和相位滞后。
- 右图：对照 `x2` 与原正弦输入的解析导数。

`x2` 是 TD 内部平滑信号的变化率状态，对原输入的微分具有滤波动态。
离散实现还带有近似误差，不能要求它与原输入的解析导数处处相等。
初始跳变的普通导数不是有限函数，所以恒值输入图不伪造一条全零“真实导数”。
